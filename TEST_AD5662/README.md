# TEST_AD5662 — 独立 AD5662 测试固件

本目录是一个**只测 DAC 的独立固件**：单独编译、单独烧录，不运行主程序，也不初始化 ADC。适合在整机联调前验证 AD5662 的供电、SPI 接线、24 位帧格式、16 位码值换算和掉电模式。

测试期间**输出 MOS（PB10）与蜂鸣器（PA2）始终保持关闭**，固件只驱动 DAC。需要注意，AD5662 输出会接到后级注入网络，测 DAC 时仍应先断开功率级或确认台架安全。

## 1. 编译与烧录

- **CLion**：复制一份运行/调试配置，把 **Target 换成 `YLD_Cup_AD5662Test`**，构建下载即可；测完把 Target 选回 `YLD_Cup` 重新烧录主固件。
- **命令行**：

```bash
cmake --build --preset Debug --target YLD_Cup_AD5662Test
```

产物位于 `build/Debug/TEST_AD5662/YLD_Cup_AD5662Test.elf`。固件自带 `main()`、72MHz 时钟、GPIO 与 SPI2 初始化，只复用板级启动/中断/MSP 文件和 `AD5662/`、`OLED/` 驱动。

## 2. 接线与测量点

| STM32 | AD5662 | 说明 |
| --- | --- | --- |
| PB13（SPI2_SCK） | SCLK | 时钟 |
| PB15（SPI2_MOSI） | DIN | 数据 |
| PB12（GPIO） | SYNC | 片选，低有效 |
| 3.3V | VREF | 参考电压 |
| — | VFB | 必须接 VOUT |
| — | GND | 与 STM32 共地 |

OLED 仍使用 PA4（SCL）/ PA5（SDA）。用万用表或示波器测量 AD5662 的 **VOUT / VFB 测试点**；满量程理论值为 3.3V 减 1 LSB，实际还会受输出放大器压降和 VREF 精度影响。

## 3. 按键与界面

| 按键 | 引脚 | 作用 |
| --- | --- | --- |
| K1 | PA8 | 手动模式：目标电压 −0.1V |
| K2 | PB11 | 手动模式：目标电压 +0.1V |
| K3 | PB9 | 循环切换四种测试模式 |

```
AD5662 TEST
MODE 1/4 DC MANUAL
TGT+0.00V STEP 0.1V
CODE 00000 0x0000
DAC+0.0000V
SPI OK ERRCNT 000
K1- K2+ K3:NEXT
MOS OFF 9M CPHA1
```

`CODE` 是驱动最近一次**成功写入**的 16 位码值，`DAC` 是按 3.3V 参考电压换算的理论输出电压，不是芯片回读值。AD5662 没有 SDO，无法读回寄存器。进入掉电模式后该行标签改为 `REG`，表示寄存器仍保持 `0x8000`，但输出级已经断开。

`SPI OK/ERR` 是最近一次传输结果，`ERRCNT` 是累计失败次数。出现非零计数时先检查 PB12/PB13/PB15、共地和 SYNC 波形，再检查 SPI 相位。

## 4. 四种测试模式

| 模式 | 输出序列 | 用途 |
| --- | --- | --- |
| 1 DC MANUAL | 0 ~ 3.3V，K1/K2 每次 0.1V | 逐点对照万用表，检查单调性和量程 |
| 2 STEP | 0、1/16 … 15/16、65535，共 17 点，每点 0.75s | 用台式表做线性度 / 阶梯检查 |
| 3 EXTREMES | 0 → 32768 → 65535 循环，每点 1.5s | 快速检查零点、半量程、满量程 |
| 4 POWERDOWN | 正常 → 1kΩ 到地 → 100kΩ 到地 → 高阻，每项 2s | 检查 PD1/PD0 与输出级行为 |

掉电模式固定使用 `0x8000` 码值：正常模式下应先看到约 1.65V，进入 1kΩ/100kΩ 到地后输出接近 0V，高阻模式下由外部网络决定电平。切回其他模式时驱动会写新码值，自动恢复正常输出。

## 5. 预期值（VREF = 3.3V）

| 目标电压 | 码值 | 十六进制 | 理论输出 |
| --- | --- | --- | --- |
| 0V | 0 | `0x0000` | 0V |
| 0.5V | 9930 | `0x26CA` | 0.4999V |
| 1.0V | 19859 | `0x4D93` | 0.9999V |
| 1.65V | 32768 | `0x8000` | 1.65V |
| 2.0V | 39719 | `0x9B27` | 1.9999V |
| 3.3V | 65535 | `0xFFFF` | 3.29995V |

手动模式以 0.1V 为步进，浮点取整后的码值可能与上表整伏点相差 1 个码值，属正常现象。

## 6. SPI 时序说明

本固件按 AD5662 手册使用 **CPOL = 0、CPHA = 1**（CubeMX 中的 **2 Edge**），9MHz，MSB 先行。器件在 SCLK 下降沿锁存 DIN；相位选错时常见现象是输出不动、始终接近 0V 或码值整体错位。

当前主固件的 `MX_SPI2_Init()` 仍是 `SPI_PHASE_1EDGE`，这是工程里尚未修正的待办项。本测试程序故意使用正确相位，烧录它即可单独验证 DAC 侧时序；若需要对比错误配置，可把 `ad5662_test_main.c` 顶部的 `TEST_SPI_PHASE` 临时改成 `SPI_PHASE_1EDGE` 后重新编译。

## 7. 排查顺序

1. 屏幕不亮：先按 [TEST_OLED/README.md](../TEST_OLED/README.md) 检查 PA4/PA5 和 OLED 地址。
2. 屏幕正常但 `SPI ERR`：检查 PB12/PB13/PB15、3.3V、GND 和 SYNC 是否空闲高。
3. SPI 一直 OK，但 VOUT 不动：确认 VFB 已接 VOUT、VREF 为 3.3V，再用示波器看 SYNC 是否包住完整的 24 个时钟。
4. 输出电压只有预期的一半、两倍或码值不成比例：优先核对 CPOL/CPHA 和帧对齐，再检查 DIN/SCLK 是否接反或存在虚焊。
5. 满量程略低于 3.3V 属正常：65535 对应 VREF 的 65535/65536，且输出放大器接近正轨时会有压降。

本固件不包含 ADC 采集、闭环控制、保护逻辑和功率输出，测完请重新烧录主固件或标定固件。
