# TEST_OLED — 独立 OLED 测试固件

本目录是一个**只测屏幕的独立固件**：单独编译、单独烧录，不运行主程序，也不初始化 ADC / DAC，适合在装机前快速检查 0.96 寸 128×64 I2C OLED 的硬件与驱动。

## 1. 编译与烧录

- **CLion**：复制一份运行/调试配置，把 **Target 换成 `YLD_Cup_OLEDTest`**，构建下载即可；测完把 Target 选回 `YLD_Cup` 重新烧录主固件。
- **命令行**：

```bash
cmake --build --preset Debug --target YLD_Cup_OLEDTest
```

产物位于 `build/Debug/TEST_OLED/YLD_Cup_OLEDTest.elf`。固件自带 `main()`、170MHz 时钟（HSE 8MHz → PLL）和 GPIO 初始化，只复用板级启动/中断/MSP 文件与 `OLED/` 驱动。

## 2. 接线

| OLED 引脚 | 板子引脚 |
| --- | --- |
| VCC | 3.3V |
| GND | GND |
| SCL | PB3 |
| SDA | PB4 |

驱动采用软件 I2C，模块一般自带 SDA/SCL 上拉电阻。PB3/PB4 复位后是 JTAG 引脚，本工程只用 SWD，测试固件里可作普通 GPIO。若换线或换屏，先确认模块是 **SSD1306、I2C 地址 0x3C（写地址 0x78）**；SH1106 屏需要按 [OLED/README.md](../OLED/README.md) 修改 `OLED_SetCursor()`。

## 3. 操作

上电先全白 0.4 秒、全黑 0.2 秒，然后进入测试页。默认每 3 秒自动翻页。

| 按键 | 引脚 | 操作 | 作用 |
| --- | --- | --- | --- |
| K1 | PA8 | 短按 | 上一页 |
| K2 | PB11 | 短按 | 下一页 |
| K3 | PB9 | 短按 | 自动翻页 开 / 关 |
| K3 | PB9 | 长按 0.8 秒 | 蜂鸣器 开 / 关 |

手动翻页会重新计时。自动翻页关闭后仍可用 K1/K2 翻页，动画页继续刷新。蜂鸣器由 PA2 高电平驱动，开启后会持续响；第 0 页和第 5 页会显示 `AUTO` / `BUZ` 状态。

## 4. 六个测试页

| 页 | 内容 | 检查什么 |
| --- | --- | --- |
| 0 | `OLED TEST`（8×16）、`YLD Cup 128x64`（6×8）、`你好世界`（16×16 汉字）、按键/蜂鸣器状态 | 字符、中文字模、边框是否完整，按键状态是否正确 |
| 1 | 1px 边框 + 交错单像素点阵 | 坏点、缺行、缺列、像素粘连 |
| 2 | 1px/2px 垂直与水平条纹、1px 棋盘格 | 行列驱动、串扰、条纹是否均匀 |
| 3 | 0% / 25% / 50% / 75% / 100% 五档密度竖条 | 亮度/对比度一致性、局部发暗或发亮 |
| 4 | 对角线、矩形、圆、实心圆、三角形 | 直线算法与图形绘制是否正常 |
| 5 | 左右移动方块 + 进度条 + 页码 + 蜂鸣器状态 | 连续全屏刷新的速度、闪烁与撕裂 |

正常屏应看到清晰的单像素点、边界笔直、条纹无断线；静态页不应闪烁，动画页方块移动平滑。若花屏或认不到屏：

1. 确认 VCC/GND、PB3/PB4 接线与模块地址；
2. 在 `OLED/OLED.c` 的 `OLED_W_SCL()` / `OLED_W_SDA()` 里加少量延时，排除软件 I2C 过快；
3. 检查模块是否 3.3V 供电、上拉电阻是否正常。

## 5. 说明

- 测试固件只配置按键、蜂鸣器（PA2）和输出 MOS（PA1）引脚；蜂鸣器由长按 K3 手动控制，输出 MOS 始终保持关断，**不会开启功率输出**。
- 页面绘制全部走 `OLED_DisplayBuf` + `OLED_Update()`，可顺便验证驱动的显存和整屏刷新路径。
