基础版本 **V2.08** 按《实验数据V2.pdf》先完成第二页 DAC 两步拟合，再完成第一页 ADC 电压残差校准。完整公式、用户确认修订、范围与验证见 [2026-10-27 电压校准说明](voltage_v2_2026-10-27.md)。下文保留 V2.06 的历史基础校准，电流系数继续使用；原电压回代误差描述的是 V2.06，不代表叠加新 trim 后的结果。

## V2.06 历史基础校准

本版根据 2026 年 10 月 25 日提供的 35 组台架记录，校正 OLED 的输入电流、输出电流和输出电压。主程序及独立恒流调参程序使用同一份 `Core/Inc/measurement_calibration.h`。本版改变测量换算；DAC 设定关系、按键、保护阈值及主程序尚未实现的恒流闭环保持原状。

## 数据与测量位置

`measurements_2026-10-25.json` 逐格保存原表的文本，包括空值与疑似笔误。表中前面的电压、电流是外部仪表参考值，“测得”四列是原版 OLED 读数，用户已确认输入参考电压在 D4 二极管之前。PA7 在 D4 之后，二者不能直接作为同一节点拟合。

两路电流使用全部 35 组。输出电压使用 32 组，以下数据只从电压拟合中排除，其他有效通道继续使用：

| 测试次数 | 输出电压问题 | 处理 |
| --- | --- | --- |
| 1 | 外表输出电压为 `x` | 不由功率除以电流反推，不补值 |

## 电流计算

先重建 V2.05 的名义电流 `x = ADC 引脚电压 / (0.020Ω × 50)`，即 `x = ADC 引脚电压 × 1 A/V`。对每路采用独立的二次最小二乘拟合：

```text
Iin  = -0.034945412 × x² + 0.999320076 × x - 0.001765326
Iout = -0.019039246 × x² + 1.007293868 × x - 0.010019176
```

结果单位为 A，负值钳为 0。没有上电自动归零。相比单一直线，二次曲线可减小本表高负载区的系统残差，系数由全部有效记录拟合，不按单行强行匹配。

实测参考输入电流覆盖 0.071 至 1.214A，输出电流覆盖 0.101 至 2.001A。对应旧 OLED 名义值上限分别为 1.27A 和 2.07A。超出上限后采用上限处的正斜率切线延伸，不把电流封顶在校准范围内，保证超量程电流仍可进入过流判断。全 ADC 量程检查换算单调不减；范围外精度尚未实测，2.3A 保护点仍需台架确认。

## 输出电压计算

先保留 `Vnominal = PA6 引脚电压 × 7`，再用已经校准的输出电流 `Iout` 做经验补偿：

```text
Vout = 1.015199746 × Vnominal - 0.055152991 × Iout - 0.016400710
```

结果单位为 V，负值钳为 0，PA6 读到真实 0V 时仍返回 0。该关系描述实测读数与端子仪表读数的差异，不能把各项系数分别认定为某个器件的独立参数。

电压组采样后更新 `measVoutNominal`；电流组采样后也用该名义值重算电压，避免负载变化时补偿停留在旧电流，且不会对已修正电压重复修正。两组采样沿用现有时隙调度，因此负载瞬变时并非同步测量。待机和保护时主屏 Vout 显示 0 仍只表示输出禁用，Q3 断开负端时正端仍可能带电。

输出电压参考值仅覆盖约 7.633 至 14.48V，且大部分负载扫描位于 8V 设定值附近；不能据此保证 5 至 15V 所有负载组合的精度。15V 设定时外表实测 14.48V 是实际输出能力的记录，本版不会将显示值强行改成设定值。DAC 的 A/B 未改，没有将负载压降拟合为固定 DAC 偏移。

## 输入电压口径

`Vin = PA7 引脚电压 × 7`，表示 D4 后的输入电压，欠压阈值仍是该节点的 12.5V，恢复阈值仍为 13.0V。原表 16V 电源入口与板端约 15.3 至 15.5V 的差值含 D4 和连线压降，不能直接改比例让 OLED 恒等于 16V。12V 那组压差又明显不同，现有数据不足以建立可靠的跨电压二极管补偿模型。

若要让 Vin 表示电源入口实测值，应增加该节点采样，或在相同电流、温度条件下同时测量 D4 两端；本版没有用虚构的固定压降抬高 Vin。

## 重现与发布

```bash
python3 calibration/fit_measurements.py
python3 tests/run_measurement_calibration.py
python3 tests/run_main_logic.py
python3 tests/run_module_logic.py
python3 tests/run_cc_pid.py
cmake --preset Release
cmake --build --preset Release
```

拟合脚本只依赖 Python 标准库，可从任何目录运行。它重新生成共享头文件及数值审计。主机验证会将原记录送入固件实际使用的 C 函数，并检查零值、全 ADC 量程单调性、校准上限衔接和过流余量；主程序模拟覆盖电流刷新后的电压重算、ADC 故障、欠压与过流计时、按键和 DAC 限幅。模块测试及恒流调参算法回归测试另行通过。

正式版使用 Release 构建。主程序 `YLD_Cup_V2.06_Release.hex` 用于正常烧录；`YLD_Cup_CCPIDTune_V2.06_Release.hex` 是单独的调参固件，需选择后独立烧录。BIN 写入地址为 `0x08000000`，HEX 自带地址。源文件包保留完整工程，未包含个人 IDE 配置和构建目录。

V2.05 修改前的源码及原有 Debug ELF/HEX/BIN 单独备份。V2.06 已完成软件验证和构建，未烧录，仍需以新的独立台架读数复核。主程序 `App_ControlStep()` 仍为空，不能将其恒流模式作为已经实现的恒流闭环使用。
