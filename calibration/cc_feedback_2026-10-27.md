# V2.13 主程序恒流快调与稳态微调

主程序 `Core/Src/main.c` 的 CC 状态已接入电流闭环。先快速缩小电流误差，接近目标后减小增益和 DAC 变化率。参数是软件验证的初值，尚未在实际板卡整定；文中的合成模型结果不代表实测精度或稳定时间。

## 操作

待机短按 K3 进入 CV，再长按 K3 切入 CC；CC 下 K1/K2 每次调整 0.1A，设定范围为 0.2～2.0A、默认 1.0A。短按 K3 回待机，长按切回 CV。CV 的电压设定单独保留；CC 最高输出电压固定为 `CC_VOLTAGE_LIMIT_V`，默认 15V。

验证使用电阻负载或电子负载的 CR 模式，按目标电流、所需电压与功耗选择负载。电子负载的 CC 模式适合验证板端 CV，不适合直接用来整定板端 CC。

## 控制与参数

本板为负增益通路：DAC 电压下降会提高输出电压及电流。每个有效电流样本进行以下更新：

```text
dt = 本次与上次有效控制样本的实际时间差（秒）
I_filtered += dt / (0.030 + dt) × (I_measured - I_filtered)
e = I_target - I_filtered
e_dead = sign(e) × max(abs(e) - 0.005A, 0)
DAC增量 = clamp(-Ki × e_dead × dt, -rate × dt, rate × dt)
DAC命令 = clamp(上一命令 + DAC增量, 电压上限对应DAC, 3.1V)
```

| 参数 | 默认值 | 行为 |
| --- | --- | --- |
| `CC_FAST_KI` / `CC_FINE_KI` | 0.8 / 0.3 DAC V/(A·s) | 大偏差快调，接近后微调 |
| `CC_FAST_RATE_V_S` / `CC_FINE_RATE_V_S` | 0.5 / 0.03 DAC V/s | 每次变化量按真实时间限速 |
| `CC_FINE_ENTER_A` | 0.030A | 原始和滤波误差均不超过 ±30mA 时进入微调 |
| `CC_FINE_EXIT_A` | 0.080A | 任一误差超过 ±80mA 时回到快调 |
| `CC_DEADBAND_A` | 0.005A | 滤波误差在 ±5mA 内保持命令 |
| `CC_CURRENT_FILTER_S` | 0.030s | 控制测量滤波，与 OLED 的显示平均独立 |
| `CC_CONTROL_PERIOD_MS` | 10ms | 最小控制间隔，仍需新电流样本 |
| `CC_CONTROL_MAX_GAP_MS` | 250ms | 首样本/长间隔只重建滤波，禁止补积历史误差 |
| `CC_VOLTAGE_LIMIT_V` | 15V | 按实测模型限制命令，测得达到上限时禁止继续升压 |
| `CC_VOLTAGE_MARGIN_V` / `CC_VOLTAGE_KI` | 0.05V / 0.2 | 新电压测得超过 15.05V 时追加缓慢降压修正 |

快慢档带迟滞，30～80mA 区间保留原档位。稳态变化率较小，滤波与死区抑制采样噪声造成的来回调节；原始电流已经到达目标一侧时，不允许滞后的滤波误差继续推动同向修正。±5mA 是控制死区，不是对仪表精度或板上电流纹波的承诺。

## 切换、限幅与保护

- 运行中 CV→CC 以最近实际写入的量化 DAC 电压初始化，不突然跳到另一工作点。由待机/保护进入 CC 则先置 DAC 3.1V，再开启输出并逐步跟踪。3.1V 只是硬件可用的低输出档，不能保证实际输出为零；原有输出电容也不会瞬间放电。
- 更改电流目标保留当前 DAC 命令，重新允许快调；目标到边界未变化时保持当前档位。离开 CC、进入保护或待机时清空滤波和新样本状态。
- 命令本身就是积分状态，限幅后不积攒额外误差，因此退出饱和时无需先释放长时间积累的积分。亚 DAC 码值的微小修正留在 RAM，避免每次单独舍入使小误差永远无法修正。
- CC 采样沿用电压:电流=1:4。`ccCurrentFresh` 与过流保护的 `ioutFresh` 独立，保护消费样本不会吞掉控制样本。电流采样失败立即关断；重复调用控制不会重复积分旧样本。
- 欠压、过流和 ADC 故障保护仍先于控制执行。输入低于 12.5V，或电压样本超过 250ms 未更新时，禁止继续升压，仍可降低电流；非有限数据直接进入 ADC 故障。
- 默认最高电压为 15V，最低输出由 DAC 3.1V、功率级与负载决定。目标电流对应的 `I×R` 超出可调电压范围时无法恒流。空载时也不会为了追求非零电流而无限升压。软件电压约束受原标定、ADC 与采样间隔限制，不是新增的独立硬件过压保护。

调试观察 `ccDacV`、`dacAppliedV`、`ccFilteredIout`、`ccFineControl`（0=快调，1=微调）和 `ccLimited`（DAC 边界或电压上限）。电流控制使用实时采样；OLED 仍使用约 300ms 的显示平均。不要在输出开启时打断点来评估连续运行效果。

## 软件验证与上板复核

`python3 tests/run_cc_regulation.py` 直接调用主程序用户区函数，覆盖控制方向、快慢迟滞、正负死区、噪声、真实时间与计时回绕、重复样本、长间隔、限速、饱和反向退出、目标与模式切换、保护优先以及电压受限后的恢复。

合成动态测试使用实际采样调度、测量换算、12 位 ADC/DAC 量化、10～80ms 的循环抖动，假设 20～300ms 的一阶功率级，并在部分工况加入 30ms 时延；测试目标升降 0.1A、负载电阻下降 10%，以及从电压上限恢复到可达目标。四种工况最初进入 ±30mA 的时间约 4.8～10.5s，末尾 15s 的最大误差约 4.2～11.3mA。负载突变会产生瞬时电流偏差，软件无法消除采样之前已经出现的尖峰。这些模型用于检查算法行为，不是本板动态模型。

构建主程序：

```sh
python3 tests/run_main_logic.py
python3 tests/run_cv_regulation.py
python3 tests/run_cc_regulation.py
cmake --build --preset Debug --target YLD_Cup
cmake --preset Release
cmake --build --preset Release --target YLD_Cup
```

上板先选择已校准且功率足够的电阻负载，检查 0.5A、1A 及目标升降 0.1A 时的实际电流，再扩展至需要的 0.2～2A 范围。记录万用表电流、输出电压、最大偏差及进入稳定范围的时间。若快调振荡先降低 `CC_FAST_KI` / `CC_FAST_RATE_V_S`；若稳态仍摆动则降低 `CC_FINE_KI` 或增大滤波时间，调整后重测多个负载。低电流工况还需确认最低输出电压是否允许达到设定值。

独立 `TEST_PID` 调参固件继续保留，可用于实测 PI/PID 初值；它的算法与节拍独立，不能把识别出的三个系数直接填进此处的分档积分控制器。
