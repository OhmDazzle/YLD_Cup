# V2.10 恒压运行中自动修正 DAC

用户反馈：设定 8V，电子负载恒流 2A，万用表与 OLED 同时缓慢下降，约 0.01V/min，FB 引脚电压也下降。工程当前为 V2.08，因此本版以 V2.08 的两步拟合和 ADC 校准为基础，加入运行中的慢速电压反馈。偏置从 0 开始，由实测输出误差学习。

## 调节原理

原两步拟合仍计算目标电压、电流对应的前馈 DAC 电压。新控制器使用校准后的 PA6 输出电压估计值，叠加一个小的 DAC 偏置：

```text
DAC命令 = 两步拟合前馈 + 慢速偏置
误差 e = 设定电压 - 滤波后的输出电压
偏置增量 = -0.020 × 死区处理后的 e × 实际经过秒数
```

本板是负增益通路：输出低于目标时，偏置减小，DAC 电压降低，从而提高电源输出；输出高于目标时反向调节。这个过程是运行中的慢速积分电压闭环，不重新拟合原系数，也不改写 ADC 换算。FB 引脚没有接到本程序 ADC，程序不能测量或校准 FB 本身。

使用时板端进入 **CV 模式，设定 8V**，电子负载选择 **CC 模式、2A**。主程序的 CC 状态仍未实现恒流调节；独立恒流调参固件也不使用这层电压纠偏。

## 参数与边界

参数集中在 `Core/Src/main.c` 的 `CV_TRIM_*` 宏中：

| 参数 | 初值 | 用途 |
| --- | --- | --- |
| `CV_TRIM_PERIOD_MS` | 100ms | 至少相隔 100ms，并取得新的电压样本，才更新积分 |
| `CV_TRIM_SETTLE_MS` | 400ms | 合闸或改变目标后等待输出稳定，随后首个样本建立滤波初值 |
| `CV_TRIM_MAX_GAP_MS` | 500ms | 超过该控制间隔只重建滤波；电流样本超过该年龄也暂停积分 |
| `CV_TRIM_FILTER_S` | 0.5s | 一阶低通时间常数，独立于 OLED 显示平均 |
| `CV_TRIM_DEADBAND_V` | 0.010V | 误差绝对值在 10mV 内不追加积分，超出后扣除死区再积分 |
| `CV_TRIM_KI` | 0.020 | 单位为 DAC V/(输出误差 V·s)，增益方向在公式中取负 |
| `CV_TRIM_RATE_V_S` | 0.005V/s | 慢速偏置的最大变化率；前馈和按键调压沿用原处理 |
| `CV_TRIM_MAX_DAC_V` | ±0.100V | 相对前馈的最大 DAC 偏置，约对应 ±0.45V 的输出调节量 |
| `CV_TRIM_MAX_ERROR_V` | 1V | 原始或滤波输出误差超过 1V 时暂停追加积分 |

最终 DAC 命令仍限制在 0.2-3.1V。积分状态本身同时受物理 DAC 范围和偏置范围约束，达到边界后不积攒隐藏误差，误差反向时可退出饱和。`cvTrimLimited` 为 1 表示纠偏已到边界，需要检查输入、负载和硬件状态。

欠压、过流与 ADC 故障检查仍优先于控制执行。即使尚处在原有保护确认或屏蔽期间，输入低于 12.5V 或测量电流超过 2.3A 也不追加积分。检测到非有限测量值立即进入 ADC 故障并关输出。

电压样本使用独立的 `cvVoltageFresh`，不与保护共享消费标志；电流组对缓存电压的重算不触发新积分。时间按实际毫秒差计算，不按主循环次数累计；长时间调试暂停不补积期间的误差。

待机、保护、模式切换或有效目标电压改变时，偏置和滤波状态清零。按键已经到调压上下限、目标没有变化时保留偏置。所有运行中修正只存在 RAM 中，不写 Flash，重新上电后重新学习。

## 软件验证

```sh
python3 tests/run_cv_regulation.py
python3 tests/run_main_logic.py
python3 tests/run_voltage_calibration.py
python3 tests/run_measurement_calibration.py
python3 tests/run_module_logic.py
python3 tests/run_cc_pid.py
python3 tests/run_buzzer_logic.py
cmake --preset Release
cmake --build --preset Release --target YLD_Cup
```

新增测试直接提取实际 `main.c` 用户区函数，覆盖方向、同一样本不重复积分、真实时间及计时回绕、死区、限速、偏置/物理限幅、饱和退出、目标和状态重置、样本新鲜度及保护优先级。

另使用假设的一阶负增益电源模型、量化后的 ADC/DAC 和抖动的循环间隔，模拟 8V/2A 下初始偏高 0.06V，随后连续 20 分钟按 0.01V/min 下降。软件模型结果约为最终 **7.9885V**，首分钟以后最大绝对误差约 **13.01mV**。这些是合成模型结果，不是本板独立实测精度，也不是已完成真实功率级动态整定的证明。

## 上板复核

烧录主固件后，在相同的 8V、CC 负载 2A 条件下，记录冷机、5 分钟和 10 分钟时的万用表电压、OLED 电压、电流、PA4 和板端输入电压。使用 Debug 构建调试时可在 Watch 中查看 `cvTrimDacV`、`cvFilteredVout`、`cvTrimLimited`。修正只相信 ADC 的端子电压估计，ADC 的温漂仍需外部仪表独立复核。

FB 持续下降也可能表示功率级已失去调节余量；本功能只能在上述有限范围内纠偏，不能修复供电不足、散热或器件问题。若偏置达到限幅而输出仍下降，应排查硬件原因。
